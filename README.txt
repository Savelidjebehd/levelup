LEVEL UP: установка на iPhone без Mac

1. Создайте бесплатный аккаунт на github.com и новый публичный репозиторий (например levelup).
2. Нажмите Add file > Upload files, перетащите ВСЕ файлы из этой папки (index.html, sw.js, manifest.webmanifest, три png) и нажмите Commit changes.
3. Settings > Pages > Source: Deploy from a branch > Branch: main, папка /(root) > Save.
4. Через 1-2 минуты откроется адрес https://ВАШ-ЛОГИН.github.io/levelup/
5. Откройте его в Safari на iPhone > кнопка Поделиться > На экран «Домой».
6. Один раз откройте приложение с интернетом. Дальше оно работает офлайн.

Данные хранятся на телефоне. Делайте резервную копию: Настройки > Скопировать данные > вставьте в Заметки.
